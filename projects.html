Projects

Cloudy with a Chance of LoRa (Weather Station)

A distributed weather station installed at Otago Polytechnic, designed to collect and publish environmental data for the Dunedin community.

I worked across embedded systems and full-stack web development, focusing on reliable data transmission, backend architecture, and hardware integration.

  • Next.js: Built a full-stack application using Next.js API routes, allowing sensor data to be processed without a separate Express server.
  • LoRa & IoT: Transmitted sensor data from Arduino-based nodes via LoRa to The Things Network, gaining hands-on experience with IoT pipelines.
  • The Things Network (TTN): Configured webhooks to forward incoming data to the backend, providing my first experience working with event-driven systems.
  • 3D Modelling & Hardware: Designed and 3D-printed weatherproof sensor enclosures, ensuring durability and ease of maintenance.

Rainy Arcade

A modern arcade machine prototype designed for use in game jams and by game development students at Otago Polytechnic.

I was responsible for backend development and cabinet design, working closely with stakeholders to ensure reliability and usability.

  • Backend Development: Built a Node.js backend using child processes to safely launch and manage games, ensuring only one game could run at a time.
  • System Control: Implemented programmatic safeguards to handle crashes and enforce correct game loading behaviour.
  • 3D Modelling & Fabrication: Designed the arcade cabinet and produced detailed construction drawings for fabrication by the engineering workshop.

CO₂ Monitoring System

A supporting project developed alongside the weather station, focused on monitoring classroom CO₂ levels to improve indoor air quality.

I contributed to both hardware and firmware development, with an emphasis on reliability and ease of repair.

  • Hardware Design: Redesigned the original system to improve modularity and repairability, replacing soldered connections with header pins and jumper cables.
  • Arduino Programming: Programmed Arduino Feather boards to read CO₂ sensor data and transmit it via a TinyLoRa module to The Things Network.
